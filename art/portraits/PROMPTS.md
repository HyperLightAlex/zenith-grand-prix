# Pilot portraits: ChatGPT prompts

Copy each prompt as it is. The images to attach are in this kit:

- `style-reference.png`: four of the game's pilots, for the style.
- `layout-guide.png`: where the head sits in the frame.
- `colour-key.png`: the flat colours to paint in.
- `pilots/`: the fifteen pilots, for step A0.

**For every image:** square, 1024 x 1024. Download the result as PNG and
save it under the name given.

**Edit steps** change one area of an image you already have. Open that
image in ChatGPT (or attach it), use the **Select** tool to brush over the
area named, then paste the prompt. Everything outside that area should stay
the same. If ChatGPT redraws the whole picture so the face or head changes,
undo and try again with a smaller selection. If it keeps doing it, note
which step.

**After each stage**, send me the files. I check them in the game before the
next stage.
